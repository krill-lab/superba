# Claude Code settings catalog

- `claude-code-settings.schema.json` — the Claude Code settings schema from
  [SchemaStore](https://github.com/SchemaStore/schemastore) (`claude-code-settings.json`,
  retrieved 2026-10-18), licensed under the Apache License 2.0. Unmodified.
- `binary-keys.json` — names and value types of settings keys that the installed Claude Code
  accepts but the SchemaStore schema does not list. Only the key names and types are recorded;
  no text from Claude Code is included.
- `zh.json` — Chinese names and explanations written for Superba.

Refresh with `scripts/catalog/claude_catalog.py`.
