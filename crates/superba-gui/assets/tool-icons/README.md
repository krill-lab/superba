`codex.svg` is single-colour (`currentColor`): Superba draws it black on light
backgrounds and white on dark ones. The PNGs carry their own plate and are
used on both.

WorkBuddy (and WorkBuddy AI): no logo is published under a license that allows
redistribution (Tencent's MIT packages `@tencent-ai/agent-sdk` and
`@tencent-ai/workbuddy-cloud-sdk` ship only CodeBuddy's artwork). Superba
ships none and shows the icon of the copy installed on the computer instead,
read from the app (the Windows program's icon resource, the macOS bundle's
`.icns`, the Linux package's `hicolor` icon); without one it keeps the `wb`
monogram.
