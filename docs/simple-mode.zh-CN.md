# 简单模式

简单模式面向主要使用 Codex 的用户，默认开启。左上角标题栏用带图标的滑动分段控件切换模式：左侧“简单”，右侧“完整”。选择会保存，下次启动继续使用。切换时水滴波纹从控件扩展到整个窗口，再淡出；开启“减少动态效果”时直接切换。

程序启动时，在首轮状态读取和启动恢复结束前，显示纯色背景与拿放大镜检查服务器的虾，下方显示“正在读取当前状态与配置...”。虾的身形、眼睛与配色和会话迁移动画一致，放大镜循环摆动，服务器指示灯轻轻闪动。开启“减少动态效果”时显示静止画面。读取结束后直接进入页面；读取失败时显示原有错误入口，后续后台刷新不会重新遮住界面。

## 页面

| 页面 | 内容与操作 |
| --- | --- |
| 概览 | 请求路径、线路、快速切换供应商、Codex 用量四张卡片。直连时隐藏本地路由节点。Codex、供应商、模型节点均有悬停反馈；点击 Codex 联网检查客户端和 CLI 的版本；点击模型打开三档速度面板。 |
| 供应商 | 供应商列表、当前线路标记及切换、账户与用量、API Key 保存与替换。所有线路位于同一卡片内，用灰色分隔线区分各行；详情卡片之间保持紧凑间距。账户卡片含近 7 天花销、日均花费、花费最多的模型。 |
| 会话与用量 | 上方是最近 24 小时 Codex 请求的统计，中间是整批会话迁移与回滚，下方是含完成时间的请求列表，默认每页 30 条，可选择 50 条。悬浮或点击“这是什么？”可查看迁移说明。 |
| Superba | 固定在侧栏底部。“信息”选项卡包含应用信息、概况、Superba 与 Codex 更新、存储占用、关于；“设置”复用完整模式的全部设置。更新列表下方可进入完整模式。 |
| 疑难解答 | 位于 Superba 上方，带问号图标。目前仅保留空白占位页和标题。 |

简单模式的用量查询只包含 Codex。完整模式中选过的工具、供应商及请求筛选不会影响这里的统计。

窗口高度不足时，页面会按卡片的实际高度提供滚动范围，滚到底部可以看见完整卡片。安装 Codex 客户端时，请求路径的版本标签忽略由厂商维护的 CLI，仅使用客户端与可由 Superba 更新的 CLI 状态。

速度面板不重复显示模型编号，用蓝、绿、紫分别表示标准、Fast、UltraFast。选择或拖动滑条预览档位时，滑块与填充色平滑过渡，再点击右上角的“✓ 应用修改”；关闭面板会放弃未应用的选择。Fast 与 UltraFast 使用动态渐变、横向星尘与柔和光晕，UltraFast 的粒子移动速度更快。当前供应商或模型不支持的选项不可选；“减少动态效果”开启时流光保持静止。官方 ChatGPT 登录的速度仍由 Codex 客户端自身选择。

简单模式的 Superba 更新数字只统计 Superba、Codex 客户端和本地 Codex CLI，最多三项。其他工具和远程主机的更新不计入该数字。

Superba 信息页的“概况”右侧可点击“重新检查”，重新读取当前状态、诊断和更新信息；“重新检查”及存储占用的“刷新”使用相同的刷新图标。

热重启倒计时期间在后台持续检测运行中的对话，包括重新开始的任务。检查进行中或读取失败时保留正常倒计时与文案；检测到运行中的对话后才暂停，直到确认结束才继续。点击“等待完成”不会提前恢复倒计时；等待期间遇到不完整的检测结果时仍保持等待。计时结束后，执行流程还会重新检查对话状态。

## 会话操作

会话迁移动画每 4 秒完成一箱的搬运与返回。虾放下箱子转身返回时，右侧箱子下沉进入地洞，同时从左侧地洞升起，在虾回来后接上下一轮搬运。

“全部迁移到 openai”会在停止 Codex 写入后，把所有非 `openai` provider 的会话一次迁移到 `openai`，包含归档会话和关闭进程期间新增的会话。操作自动备份，等待正在进行的请求结束，并通过原有流程停启 Codex。等待期间可以取消。

存在未回滚的迁移记录时显示“全部回滚”。它会从最新记录开始，依次恢复全部未回滚记录，只停启一次 Codex。迁移后又被修改的内容仍受现有保护，跳过时会报告；不会覆盖这些新内容。

## 手动验收

1. 退出旧版 Superba（包括托盘中的进程），打开构建目录中的 `superba.exe`。简单模式下侧栏有概览、供应商、会话与用量，底部依次固定疑难解答、Superba；如此前选择过完整模式，点击左上角的模式按钮。
2. 在概览选择供应商，检查钥匙图标和灰色 Krill 图标、线路提示语，以及请求路径随实际切换结果更新。依次悬停 Codex、供应商、模型，确认三个节点都有背景反馈。点击 Codex 检查客户端与 CLI 版本；线路下显示延迟。
3. 点击请求路径最右侧的模型，选择标准、Fast、UltraFast，核对紧凑尺寸、颜色和后两档不同速度的星尘。选择档位时仅预览，点击“应用修改”后才保存；不可用的档位置灰。
4. 在供应商页确认当前线路高亮，点击其他线路延迟下方的“切换”。选择其他供应商时，标题右侧显示“切换到…”；账户与用量卡片位于线路和 Key 卡片之间。保存或替换 Key，并进入“进阶设置”再返回简单视图。
5. 核对账户卡片近 7 天花销、日均花费与花费最多的模型。没有成本数据时显示“—”。
6. 在会话与用量页核对完成时间，切换每页 30／50 条并前后翻页。悬浮或点击“这是什么？”查看完整迁移说明。
7. 在有运行中对话时应用一次速度或线路修改，确认倒计时暂停；对话结束后才继续。等待期间仍可取消。
8. 点击侧栏底部的 Superba，检查两个选项卡、仅包含 Superba 与 Codex 的更新、存储占用与关于。点击更新下方的按钮进入完整模式。
9. 确认左上角“简单／完整”分段控件与侧边栏第一行之间有留白。往返切换模式，观察选中背景滑动和全屏水滴过渡；关闭后重新打开，确认模式选择保存。
10. 检查简单模式的 Superba 更新数字不包含其他工具。点击其上方的“疑难解答”，确认暂时只显示占位标题。

本功能基于 `0.1.1-alpha.10`，未更改发布版本号。测试扩展在项目原有测试文件中，没有新增临时测试脚本。
